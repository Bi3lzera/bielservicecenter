# Environment Variables Documentation

This document describes all environment variables used in the Biel's Service Center application.

## Frontend Application (React + Vite)

### API Configuration

**VITE_API_BASE_URL** (Required)
- Base URL for the Laravel API backend
- Development: `http://localhost:8000/api`
- Production: `https://api.yourdomain.com/api`

**VITE_API_AUTH_URL** (Required)
- Base URL for authentication endpoints (CSRF, broadcasting auth)
- Development: `http://localhost:8000`
- Production: `https://api.yourdomain.com`

### WebSocket Configuration (Laravel Reverb)

**VITE_REVERB_APP_KEY** (Required)
- Application key for Reverb WebSocket server
- Must match `REVERB_APP_KEY` in backend `.env`
- Example: `helpdesk_key`

**VITE_REVERB_HOST** (Required)
- WebSocket server hostname
- Development: `localhost`
- Production: `your-websocket-domain.com` or `yourdomain.com`

**VITE_REVERB_PORT** (Required)
- WebSocket server port
- Development: `8080`
- Production: `443` (with HTTPS) or `80` (with HTTP)

**VITE_REVERB_SCHEME** (Required)
- WebSocket connection scheme
- Development: `http`
- Production: `https` (recommended)

## Backend API (Laravel)

### Application Settings

**APP_NAME**
- Application name displayed in emails and UI
- Example: `"Biel's Service Center"`

**APP_ENV**
- Application environment
- Development: `local`
- Production: `production`

**APP_KEY**
- Application encryption key (generated by `php artisan key:generate`)
- **CRITICAL**: Never share or commit this value

**APP_DEBUG**
- Enable/disable debug mode
- Development: `true`
- Production: `false` (REQUIRED for security)

**APP_URL**
- Base URL of your application
- Development: `http://localhost:8000`
- Production: `https://yourdomain.com`

**APP_TIMEZONE**
- Application timezone
- Example: `America/Sao_Paulo`, `UTC`

### Database Configuration (MySQL)

**DB_CONNECTION**
- Database driver
- Production: `mysql` (per user requirement)
- Development: `sqlite` (optional)

**DB_HOST**
- Database server hostname
- Common: `127.0.0.1` or `localhost`

**DB_PORT**
- Database server port
- MySQL default: `3306`

**DB_DATABASE**
- Database name
- Example: `helpdesk_production`

**DB_USERNAME**
- Database username
- Example: `helpdesk_user`

**DB_PASSWORD**
- Database password
- **CRITICAL**: Use a strong, unique password in production

### Session Configuration

**SESSION_DRIVER**
- Session storage driver
- Production: `database` (current) or `redis` (for better performance)

**SESSION_LIFETIME**
- Session lifetime in minutes
- Default: `120` (2 hours)

**SESSION_SECURE_COOKIE**
- Only send cookies over HTTPS
- Development: `false`
- Production: `true` (if using HTTPS)

**SESSION_DOMAIN**
- Cookie domain
- Production: `.yourdomain.com` (allows subdomains)
- Development: `null`

### WebSocket Configuration (Laravel Reverb)

**REVERB_APP_ID**
- Reverb application ID
- Generate a unique ID for production

**REVERB_APP_KEY**
- Reverb application key
- Must match `VITE_REVERB_APP_KEY` in frontend
- Example: `helpdesk_key`

**REVERB_APP_SECRET**
- Reverb application secret
- **CRITICAL**: Generate a secure secret for production

**REVERB_HOST**
- WebSocket server hostname
- Production: `yourdomain.com`

**REVERB_PORT**
- WebSocket server port
- Production: `443` (with HTTPS)

**REVERB_SCHEME**
- WebSocket connection scheme
- Production: `https`

### CORS Configuration

**FRONTEND_URL**
- Frontend application URL for CORS
- Development: Not needed (localhost already configured)
- Production: `https://yourdomain.com`

**SANCTUM_STATEFUL_DOMAINS**
- Domains that should receive stateful API authentication
- Production: `yourdomain.com,www.yourdomain.com`

### Mail Configuration

**MAIL_MAILER**
- Mail driver (smtp, sendmail, mailgun, etc.)
- Production: `smtp` (most common)

**MAIL_HOST**
- SMTP server hostname
- Example: `smtp.gmail.com`, `smtp.sendgrid.net`

**MAIL_PORT**
- SMTP server port
- Common: `587` (TLS) or `465` (SSL)

**MAIL_USERNAME**
- SMTP username/email

**MAIL_PASSWORD**
- SMTP password or API key

**MAIL_ENCRYPTION**
- Encryption method
- Options: `tls`, `ssl`

**MAIL_FROM_ADDRESS**
- Default sender email address
- Example: `noreply@yourdomain.com`

**MAIL_FROM_NAME**
- Default sender name
- Usually set to `"${APP_NAME}"`

### Logging

**LOG_CHANNEL**
- Primary logging channel
- Production: `stack` (recommended)

**LOG_LEVEL**
- Minimum log level to record
- Development: `debug`
- Production: `error` or `warning`

### Cache and Queue

**CACHE_STORE**
- Cache driver
- Production: `database` or `redis` (for better performance)

**QUEUE_CONNECTION**
- Queue driver
- Production: `database` or `redis`

## Environment File Locations

- **Frontend**: `/app/.env` (development), `/app/.env.production` (production)
- **Backend**: `/api/.env`

## Security Best Practices

1. **Never commit `.env` files** to version control
2. **Use strong, unique values** for `APP_KEY`, `REVERB_APP_SECRET`, `DB_PASSWORD`
3. **Set `APP_DEBUG=false`** in production
4. **Use HTTPS** in production (`SESSION_SECURE_COOKIE=true`, `REVERB_SCHEME=https`)
5. **Restrict database user permissions** to only what's necessary
6. **Use environment-specific values** - never use development credentials in production
